# Пять потенциальных ям

Исследовательская работа по физике: численное решение стационарного уравнения Шрёдингера
методом конечных разностей для пяти потенциалов (бесконечная и полубесконечная яма,
гармонический осциллятор, ангармонические осцилляторы x⁴ и Морзе) и сравнение моделей
электрона в атоме. Эталон — атом водорода.

Сайт: `index.html` — один файл. Атлас шести ям с живыми графиками, спектры, туннелирование, вердикт и метод; справа справочник обозначений.

## Файлы

| Файл | Что делает |
|---|---|
| `index.html` | Готовая страница; все графики считаются в браузере тем же методом |
| `solver.py` | Решатель и все проверки на Python. `python solver.py` печатает уровни и пишет `results.json` |
| `page5.html`, `build5.py` | Исходник страницы и сборка: `python build5.py` |

## Запуск

```
pip install numpy scipy
python solver.py
```

## Публикация на GitHub Pages

1. Создать репозиторий и загрузить в него эти файлы.
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
